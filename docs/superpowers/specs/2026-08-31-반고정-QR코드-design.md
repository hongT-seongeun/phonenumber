# 반 고정 + QR 코드 다운로드 기능 설계

## 배경

현재 교사 화면에서는 학년만 고정할 수 있고(`g` 파라미터), 반은 "몇 반까지"라는 범위만 지정할 수 있다. 또한 완성된 링크는 텍스트로만 제공되어 교사가 복사해서 전달해야 한다.

요청 사항:
1. 학년처럼 반도 고정할 수 있게 한다.
2. 링크 생성 시 QR 코드도 함께 만들어져서 다운로드할 수 있게 한다.

## 1. 반 고정 기능

### 교사 화면 (`index.html`)

- 기존 `#grade-lock` select 옆에 `#class-lock` select를 추가하고, 두 select를 `row2`로 나란히 배치한다.
  - 옵션: `학생이 직접 선택`(값 없음), `1반으로 고정` ~ `15반으로 고정`
- `#class-lock`에 값이 선택되면 그 아래 있는 `#class-max`("반은 몇 반까지") 입력 wrapper를 숨긴다. `#number-max`("번호는 몇 번까지") 입력은 항상 표시한다.
- `#class-lock` 값이 다시 "학생이 직접 선택"으로 바뀌면 `#class-max` wrapper를 다시 보여준다.

### 링크 파라미터

- 새 파라미터 `fc`(fixed class)를 추가한다. 예: `...&fc=3` → 3반 고정.
- 반이 고정된 경우 `c`(반 범위) 파라미터는 링크에 포함하지 않는다(불필요).
- 기존 `g`(고정 학년), `c`(반 범위), `n`(번호 범위) 파라미터의 동작과 위치는 변경하지 않는다.

### 학생 화면 (`script.js`)

- 기존 `#grade-slot` 패턴과 동일하게, `#class-select`(고정 select)를 `#class-slot`(빈 컨테이너)로 바꾼다.
- `fc` 파라미터가 있으면(1~15 범위로 clamp) `.fixed-grade` 스타일을 재사용한 고정 표시 div("3반")를 `#class-slot`에 넣는다.
- `fc`가 없으면 기존처럼 `#class-slot`에 select를 만들고 `fillSelect`로 1~`classMax`까지 옵션을 채운다.
- 메시지 미리보기(`currentMessage`)와 변경 감지(`watchedEls`) 로직은 고정 여부에 따라 `classSelect`가 없을 수 있으므로 학년 고정 처리와 동일한 방식으로 분기한다.

## 2. QR 코드 생성 + 다운로드

### 라이브러리

- `qrcodejs`(davidshimjs, MIT 라이선스)를 `qrcode.min.js` 파일로 프로젝트 루트에 포함한다(이미 다운로드 완료, 19.9KB, 의존성 없는 순수 JS).
- `index.html`에 `<script src="qrcode.min.js"></script>`를 `script.js`보다 먼저 추가한다.
- CDN이 아닌 로컬 파일로 포함하는 이유: 인터넷 연결 없이도(오프라인) 더블클릭으로 완전히 동작해야 하고, 외부 QR 생성 API에 링크(전화번호 포함)를 보내지 않고 브라우저에서 직접 생성해 "번호는 어디에도 저장되지 않아요"라는 기존 안내를 지키기 위함이다.

### 동작

- `#teacher-result` 박스 안, 링크 텍스트 아래에 QR 코드를 표시할 `#qr-box`(흰 배경, 고정 크기)와 그 안의 `#qr-canvas-wrap` 컨테이너를 추가한다.
- "링크 만들기" 버튼 클릭 시 링크 생성 후:
  1. `#qr-canvas-wrap`을 비운다(`innerHTML = ''`).
  2. `new QRCode(qrCanvasWrap, { text: link, width: 160, height: 160, colorDark: '#000000', colorLight: '#ffffff', correctLevel: QRCode.CorrectLevel.M })`로 QR을 그린다.
- QR 아래 `#download-qr-btn`("⬇️ QR 다운로드") 버튼을 추가한다.
  - 클릭 시 `#qr-canvas-wrap` 안의 `<canvas>`를 찾아 `canvas.toDataURL('image/png')`로 데이터 URL을 만들고, 임시 `<a download="학생등록링크_QR.png">`를 생성해 클릭시켜 다운로드한다.
  - 링크를 다시 만들면(버튼 재클릭) 이전 QR은 지워지고 새로 그려진다.

### 스타일 (`style.css`)

- `#qr-box`에 흰색 배경 + 라운드 모서리 스타일을 추가해 어두운 칠판 배경 위에서도 QR이 잘 보이고 스캔이 잘 되게 한다(기존 `.result-box`의 dashed 테두리 톤은 유지).
- 다운로드 버튼은 기존 `.btn-ghost` 스타일을 재사용한다.

## 변경 파일 요약

| 파일 | 변경 내용 |
|---|---|
| `index.html` | 반 고정 select 추가, QR 표시 영역 + 다운로드 버튼 추가, `qrcode.min.js` 스크립트 태그 추가 |
| `style.css` | QR 박스 스타일 추가 |
| `script.js` | 반 고정 로직(교사/학생), QR 생성·다운로드 로직 추가 |
| `qrcode.min.js` | 신규 파일(외부 라이브러리, 수정하지 않음) |

## 범위 밖 (변경하지 않음)

- 학년 고정 로직 자체의 동작 방식
- 문자 전송(sms:) 로직, base64url 인코딩 방식
- 기존 디자인 톤(칠판 카드 + 밝은 배경)
